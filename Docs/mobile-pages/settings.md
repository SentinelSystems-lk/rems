# Settings Page

## What it does

This is the current settings screen.
In the web app it is mostly static placeholder UI.

## How it works

1. Render account, preference, and support sections.
2. Show a user profile card with hardcoded demo content.
3. Show app version footer text.

## Core logic

- There is no backend-backed settings flow in this page yet.
- The current web page is presentational only.
- Native should replace the hardcoded content with real profile and preference state.

## APIs used

- None currently

## Data handled

- UI labels only
- No live user or settings payload yet
